PART 5 - PRODUCTION OPTION COMPARISON
Own servers + VMs:
- Existing host capacity and VM overhead; staff/maintenance/power/cooling.
- Does not require new servers if capacity is adequate, but peak headroom may be insufficient.

Own servers + containers/Kubernetes:
- Uses current hardware more densely; replicas and resource limits isolate workloads.
- Capacity remains bounded by the existing node CPU/RAM and failure reserve.

Public cloud only:
- Elastic node capacity, hourly billing and provider-managed services.
- Recurring baseline DB/control-plane/network/storage costs; provider hosts infrastructure.

Hybrid (recommended planning option):
- Run baseline workloads on current university infrastructure.
- Burst stateless app replicas to the cloud before result day.
- Use private connectivity and a controlled database access/replication strategy.
- University retains data ownership and access policy; cloud provider operates contracted infrastructure.
