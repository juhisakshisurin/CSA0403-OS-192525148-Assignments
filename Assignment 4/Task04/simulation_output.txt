Disk scheduling simulation assumptions:
- Cylinders: 0..199; initial head: 53.
- 10,000 random requests per load; uniform cylinder selection.
- Arrival intervals are uniform in [0.5, 1.5] x the stated mean.
- Light/medium/heavy mean inter-arrival: 8.0 / 2.0 / 0.6 ms.
- Modelled service time: 0.20 + 0.020 x head movement (ms).
- Waiting time = dispatch start time - request arrival time.
- Average movement includes SCAN/C-SCAN/C-LOOK travel and wrap movement.

SSTF near-stream fairness demonstration:
- 1000 requests at cylinders 59/60/61 arrive every 1 ms.
- A request at cylinder 183 is waiting from time 0.
- SSTF serves all 1000 nearer requests before cylinder 183.
- Modelled wait for cylinder 183: 1201.320 ms (finite stream).
- If the closer stream continues indefinitely, the far request can starve.
