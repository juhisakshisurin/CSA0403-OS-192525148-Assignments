## Objective

To compare different types of operating systems and select the most suitable OS type for each computing environment in a smart hospital.

## Description

This task evaluates the following operating-system types:

- Mainframe Operating System
- Desktop Operating System
- Multiprocessor Operating System
- Distributed Operating System
- Clustered Operating System
- Real-Time Operating System
- Handheld Operating System

The suitability of each type is analysed for bedside monitors, nurses' tablets, doctors' workstations, the central database server, the MRI imaging server and communication with partner hospitals.

## Key Concepts

- Hard and soft real-time systems
- Symmetric multiprocessing (SMP)
- Asymmetric multiprocessing (AMP)
- Distributed computing
- Clustered systems
- Database fail-over mechanisms
- High availability and scalability

## Evaluation

A real-time operating system is suitable for bedside monitors because of their strict response-time requirements.

Handheld operating systems are appropriate for nurses' tablets because of their power-management and mobile-interface features.

Desktop operating systems support doctors' workstations, while multiprocessor systems support computationally intensive MRI processing.

Clustered and distributed systems improve database availability and communication across hospitals.

## Result

Suitable operating-system types were evaluated for all smart-hospital environments. The analysis demonstrates that selecting an OS according to workload, reliability, processing and response-time requirements provides a more effective solution than using a single OS type everywhere.
