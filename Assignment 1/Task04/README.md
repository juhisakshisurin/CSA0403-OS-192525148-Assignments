## Objective

To evaluate the operating-system services required by different smart-hospital environments and identify essential and optional services.

## Description

This task examines the major services provided by an operating system:

- User Interface
- Program Execution
- I/O Operations
- File-System Management
- Communication
- Error Detection
- Resource Allocation
- Accounting
- Protection
- Security

The services are evaluated for bedside monitors, handheld tablets, desktop workstations and hospital servers.

## Key Concepts

- Operating-system services
- Resource management
- File-system operations
- Device management
- Communication services
- Authentication and access control
- Memory and process protection

## Evaluation

Bedside monitors require a minimal set of essential services to reduce overhead and support predictable operation.

Database servers require comprehensive file management, communication, resource allocation, protection and security services.

Handheld tablets require power-efficient services, while doctors' workstations require user-interface and multitasking support.

## Result

The operating-system services required by each smart-hospital environment were evaluated. Essential services and services that can be minimised were identified to improve efficiency, reliability and security.
